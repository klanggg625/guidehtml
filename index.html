AI로 만든 HTML을
내 웹사이트 주소로 공개하기

ChatGPT나 Claude로 만든 HTML 파일을 GitHub와 Vercel을 이용해 누구나 열어 볼 수 있는 주소로 만드는 방법입니다. 코딩을 몰라도 따라 할 수 있도록 단계별로 정리했습니다.

전체 흐름 용어 설명 1. HTML 준비 2. 공개하기 주의할 점 막혔을 때

전체 흐름

네 단계만 거치면 주소가 만들어집니다. 처음 한 번만 설정하면 다음부터는 파일만 바꿔 올리면 됩니다.

1. AI로 만들기ChatGPT·Claude에게 index.html 한 파일을 만들어 달라고 요청
2. GitHub에 올리기만든 파일을 인터넷 보관함(저장소)에 저장
3. Vercel에 연결하기보관함의 파일을 웹사이트로 바꿔 주소 발급
4. 주소 공유하기링크를 안내문이나 QR로 전달

먼저 알아둘 세 가지 말

HTML

웹페이지를 만드는 문서 형식입니다. 파일 하나가 곧 웹페이지 하나입니다. 이 안내에서는 글, 디자인, 기능을 모두 index.html 파일 하나에 담습니다.

GitHub

파일을 올려 보관하는 인터넷 저장 공간입니다. 보관함 하나를 저장소(repository)라고 부릅니다. 수정할 때마다 기록이 남아서 이전 버전으로 돌아갈 수도 있습니다.

Vercel

GitHub 저장소의 파일을 웹사이트로 바꿔서 ○○○.vercel.app 같은 주소를 만들어 주는 서비스입니다. 이것을 배포(deploy)라고 부릅니다. GitHub의 파일을 고치면 자동으로 다시 배포됩니다.

알아두세요화면의 메뉴 이름과 위치는 서비스 업데이트로 바뀔 수 있습니다. 이 안내의 메뉴 이름은 영어 화면 기준이고, 필요한 곳에는 한글 뜻을 함께 적었습니다. 단계 이름이 조금 달라도 같은 기능을 찾아서 진행하세요.

1. ChatGPT나 Claude로 HTML 만들기

AI로 만들어진 HTML 결과물을 준비합니다.

2. GitHub와 Vercel로 주소 만들기

각 단계 끝의 확인 항목을 체크하면서 따라가세요. 체크한 내용은 이 브라우저에 저장되어 다시 열어도 남아 있습니다.

0 / 7 단계 완료
1

GitHub 가입하기

이미 계정이 있으면 다음 단계(저장소 만들기)로 넘어가세요.

  1. 인터넷 주소창에 github.com을 입력해 접속합니다.
  2. 오른쪽 위 Sign up(가입)을 누르고 이메일, 비밀번호, 사용자 이름(username)을 입력합니다.
  3. 이메일로 온 인증 코드를 입력해 가입을 마칩니다.
사용자 이름 정하기이 이름이 나중에 쓰이는 주소 일부가 될 수 있습니다. 영문과 숫자로 짧게 정하세요. 비밀번호는 반드시 본인이 직접 입력하고, 다른 사람에게 알려주지 마세요.
2

새 저장소 만들기

파일을 담을 보관함을 하나 만듭니다. 웹페이지 하나당 저장소 하나가 편합니다.

  1. 오른쪽 위 + 버튼을 누르고 New repository(새 저장소)를 선택합니다.
  2. Repository name(저장소 이름)을 입력합니다. 예: counseling-guide
    • 영어 소문자, 숫자, 하이픈(-)만 쓰고 한글은 피하세요.
    • 이 이름이 나중에 웹주소의 기본값이 됩니다.
  3. Public(공개)과 Private(비공개) 중에서 고릅니다. 둘 다 Vercel에 연결할 수 있습니다. 차이는 아래 주의할 점에서 설명합니다.
  4. 아래쪽 Create repository(저장소 만들기)를 누릅니다.
팁Add a README file 항목은 체크하지 않고 만드는 것이 따라 하기 쉽습니다. 체크하지 않으면 다음 단계의 uploading an existing file 링크가 바로 보입니다.
3

index.html 파일 올리기

준비한 HTML 파일을 저장소에 올립니다.

  1. 저장소 화면 가운데에서 uploading an existing file 링크를 누릅니다. 보이지 않으면 Add file → Upload files(파일 추가 → 파일 올리기)를 선택하세요.
  2. 준비한 index.html 파일을 화면의 점선 영역으로 끌어다 놓습니다.
  3. 파일 이름이 올라온 것을 확인하고 아래쪽 초록색 Commit changes(변경 사항 저장) 버튼을 누릅니다.
가장 중요한 규칙파일 이름은 반드시 index.html이고, 폴더 안이 아니라 저장소 맨 첫 화면에 있어야 합니다. 이름이 다르거나 폴더 안에 있으면 나중에 화면이 나오지 않습니다(404 오류).
4

Vercel에 GitHub 계정으로 가입하기

Vercel이 내 GitHub 저장소를 읽을 수 있도록 연결합니다.

  1. 인터넷 주소창에 vercel.com을 입력해 접속하고 Sign Up(가입)을 누릅니다.
  2. 요금제를 묻는 화면에서는 무료 개인용인 Hobby를 고릅니다. 이름 입력 칸이 나오면 본인 이름이나 별명을 적습니다.
  3. Continue with GitHub(GitHub로 계속하기)를 누릅니다.
  4. GitHub 권한 요청 화면이 나오면 내용을 읽고 Authorize(허용)를 누릅니다.
무료 요금제 조건Vercel의 무료 Hobby 요금제는 비상업적 개인 용도로만 쓸 수 있습니다. 수업 안내나 학교 업무용 페이지는 보통 해당하지만, 유료 강의나 수익과 연결된 용도는 별도 플랜이 필요할 수 있습니다. 자세한 기준은 아래 주의할 점을 읽어 보세요.
5

저장소를 Vercel 프로젝트로 가져오기

이 단계에서 웹사이트가 실제로 만들어집니다.

  1. 대시보드 오른쪽 위 Add New… 버튼을 누르고 Project를 선택합니다.
  2. Import Git Repository(Git 저장소 가져오기) 목록에서 2단계에서 만든 저장소를 찾아 오른쪽 Import를 누릅니다.
    • 저장소가 목록에 없으면 Adjust GitHub App Permissions(GitHub 권한 조정) 또는 Install을 눌러 해당 저장소 접근을 허용하세요.
  3. Configure Project(프로젝트 설정) 화면에서 Framework Preset이 Other로 되어 있는지 확인합니다. 다른 값이 선택되어 있다면 Other로 바꿉니다.
  4. 나머지 칸(Build Command, Output Directory 등)은 비워 두고 그대로 둡니다.
  5. 아래쪽 Deploy(배포) 버튼을 누릅니다.
왜 Other인가요?우리가 만든 것은 파일 하나짜리 완성된 웹페이지라서 따로 만드는(build) 과정이 필요 없습니다. Vercel이 index.html을 그대로 보여 줍니다.
6

내 주소 확인하고 열어 보기

드디어 인터넷 주소가 생겼습니다.

  1. 배포 완료 화면의 큰 화면 미리보기나 Continue to Dashboard를 누릅니다.
  2. 프로젝트 화면의 Domains 항목에 ○○○.vercel.app 형태의 주소가 보입니다. 이 주소를 누르면 내 웹페이지가 열립니다.
  3. 휴대폰에서도 같은 주소를 열어 화면이 잘 보이는지 확인하세요.
  4. 다른 사람에게 이 주소를 보내면 됩니다. 안내문에 QR 코드를 넣어도 좋습니다.
주소 이름 바꾸기프로젝트의 Settings → Domains에서 .vercel.app 앞부분을 원하는 이름으로 바꿀 수 있습니다. 이미 다른 사람이 쓰는 이름은 고를 수 없어서, 처음부터 저장소 이름을 독특하게 짓는 방법도 좋습니다.
7

내용을 고쳐서 다시 반영하기

한 번 연결해 두면 이후에는 GitHub의 파일만 고치면 됩니다.

  1. AI에게 수정을 요청해서 새 코드를 받습니다.
  2. GitHub 저장소에서 index.html을 누르고, 오른쪽 위 연필 모양 Edit 아이콘을 누릅니다.
  3. 기존 내용을 모두 지우고(Ctrl+A) 새 코드를 붙여넣습니다.
  4. 오른쪽 위 초록색 Commit changes를 누르고 한 번 더 확인 창에서 Commit changes를 누릅니다.
  5. 1~2분 뒤 같은 주소를 새로고침하면 바뀐 내용이 보입니다. Vercel이 자동으로 다시 배포합니다.
바뀌지 않을 때인터넷 창에서 Ctrl+Shift+R로 강제 새로고침을 해 보세요. 그래도 같으면 Vercel 프로젝트의 Deployments에서 새 배포가 끝났는지 확인합니다.
참고: 방법 2 — 터미널(Vercel CLI)로 올리기

컴퓨터에 Node.js가 설치되어 있고 터미널 사용에 익숙한 경우에만 권하는 방법입니다. GitHub 없이 index.html이 든 폴더에서 바로 올립니다.

  1. 터미널을 열고 npm i -g vercel을 입력해 설치합니다.
  2. index.html이 있는 폴더로 이동한 뒤 vercel을 입력합니다. 처음에는 로그인 안내가 나옵니다.
  3. 설정 질문은 기본값으로 진행하고, 마지막에 vercel --prod를 입력하면 실제 주소가 만들어집니다.

처음 시작하는 분께는 위의 GitHub 연결 방식이 수정과 관리 면에서 더 편합니다.

공개하기 전에 꼭 확인하세요

웹에 올리면 주소를 아는 누구나 볼 수 있습니다. 올리기 전에 아래를 확인하세요.

개인정보와 비밀번호

  • 학생 이름, 학번, 연락처, 상담 내용 등 개인을 알아볼 수 있는 정보는 파일에 넣지 마세요. 파일에 들어간 내용은 공개됩니다.
  • 비밀번호, API 키(AI 서비스 접속용 열쇠 값)를 코드에 적어 두면 누구나 볼 수 있습니다. 올리기 전에 AI에게 해당 코드를 붙여넣고 개인정보나 키 값이 들어 있는지 점검해 달라고 요청해 보세요.
  • 학교나 교육청의 생성형 AI·정보 공개 관련 지침이 있으면 함께 확인하세요.

GitHub 저장소: Public과 Private

Public(공개)Private(비공개)
코드 보기누구나 저장소에서 볼 수 있음나와 초대한 사람만 볼 수 있음
웹페이지Vercel 주소로 누구나 열 수 있음Vercel 주소로는 열 수 있음
추천 상황코드를 공개해도 되는 일반 안내 자료코드 내용을 남에게 보이고 싶지 않을 때

Private로 해도 웹페이지로 보이는 화면은 공개되므로 화면에 나오는 내용에는 같은 주의가 필요합니다.

Vercel 무료 요금제(Hobby)의 조건

  • Vercel 공식 문서에 따르면 Hobby는 비상업적 개인 용도 전용이고, 상업적 사용은 유료 플랜(Pro 등)이 필요합니다.
  • 상업적 사용의 범위가 넓게 정해져 있습니다. 배포한 것이 참여한 누구라도 금전적 이득을 얻는 목적으로 쓰이면 해당하고, 유급으로 코드를 쓰는 직원이나 컨설턴트도 포함한다고 안내하고 있습니다.
  • 학교 수업이나 학생 안내처럼 수익과 무관한 용도는 보통 개인·비상업 용도에 가깝습니다. 하지만 유료 강의, 수강생 모집, 광고와 연결되는 페이지는 애매할 수 있으니 판단이 어려우면 Vercel 지원팀에 문의하세요.

기준은 바뀔 수 있으므로 최신 내용은 Vercel 문서의 Fair Use Guidelines에서 확인하세요.

AI가 만든 코드는 한 번 눈으로 확인하기

  • 화면이 의도대로 나오는지, 글자와 내용이 맞는지 직접 확인합니다.
  • 내용 중 사실과 다른 부분이 없는지 사람이 검토합니다.
  • 이상한 기능(외부로 정보를 보내는 입력창 등)이 있으면 AI에게 빼 달라고 요청하세요.

막혔을 때

주소를 열었더니 404 NOT_FOUND가 나와요
  • GitHub 저장소 첫 화면에 index.html이 있는지 확인하세요. 폴더 안에 들어 있으면 안 됩니다.
  • 파일 이름이 index.html.txt, Index.html, 한글 이름 등이 아닌지 확인하세요. 소문자 index.html이어야 합니다.
  • Vercel 프로젝트 Deployments에서 배포가 성공(Ready) 상태인지 확인하세요.
한글이 깨져서 보여요

HTML 파일 위쪽(head 부분)에 <meta charset="utf-8">가 있는지 확인하고, 메모장에서 저장할 때 인코딩을 UTF-8로 선택했는지 확인하세요. AI에게 "한글이 깨지지 않게 charset을 넣어줘"라고 요청해도 됩니다.

Vercel의 저장소 목록에 내 저장소가 안 보여요

Import 화면에서 Adjust GitHub App Permissions(또는 Install)를 눌러 GitHub에서 해당 저장소 접근을 허용해야 합니다. 허용 후 Vercel로 돌아와 새로고침하세요.

GitHub에서 고쳤는데 주소의 내용이 안 바뀌어요
  • 수정 후 반영까지 1~2분 걸립니다.
  • 강제 새로고침(Ctrl+Shift+R)을 해 보세요.
  • GitHub에서 Edit 후 Commit changes까지 눌렀는지 확인하세요. 편집창만 닫으면 저장되지 않습니다.
다른 사람이 주소를 열면 Vercel 로그인 화면이 나와요

Vercel 프로젝트의 배포 보호(Deployment Protection) 설정 때문일 수 있습니다. 프로젝트의 Settings에서 Deployment Protection을 찾아 보호 범위를 확인하세요. 메뉴 이름과 기본값은 바뀔 수 있으니, 해결되지 않으면 Vercel 도움말을 함께 확인하세요.

저장소 이름이나 주소 이름이 이미 있다고 나와요

다른 이름으로 바꿔 시도하세요. 이름 뒤에 연도나 학교 약칭을 붙이면 겹치지 않습니다. 예: counseling-guide-2026

올린 페이지를 내리고 싶어요

Vercel 프로젝트의 Settings에서 프로젝트를 삭제하면 주소가 사라집니다. GitHub 저장소도 함께 지우려면 저장소의 Settings 맨 아래에서 삭제할 수 있습니다. 한 번 삭제하면 되돌릴 수 없으니 신중하게 진행하세요.

AI로 만든 HTML 공개 안내 · 서비스 화면과 요금 조건은 바뀔 수 있으니, 진행 중 다르게 보이면 각 서비스의 도움말을 함께 확인하세요.
